# MMDocIR 실습 데이터 명세

작성일: 2026-10-20
최종 수정일: 2026-10-28

문서별 관찰 내용과 분석 페이지를 정리한 명세서다.
문서 유형·구조·텍스트 선택 가능 여부·그림·표 정보는 사용자의 관찰이며, 파서 실행으로 검증한 결과와 구분한다.
문서별 관찰 내용을 각 선택 페이지의 개별 판정으로 확대하지 않는다.

## 범위와 입력 규칙

- 대상: PDF 9개 문서, 선택 페이지 총 27개.
- 분석 페이지: PDF 뷰어에서 첫 페이지를 1로 세는 실제 페이지 순번. 본문에 인쇄된 쪽 번호와 구분한다.
- 파일명: 아래 문서명에 `.pdf`를 붙인다. 페이지 범위 `7~8`은 `[7, 8]`로 풀어 처리한다.
- PyMuPDF 페이지 인덱스: `분석 페이지 순번 - 1`. 원래 분석 페이지 순번도 함께 보존한다.
- PDF 폴더 URL: `http://localhost:18080/raw/mmdocir_data/extracted/doc_pdfs/`.
- PDF 파일 URL: `PDF 폴더 URL + 문서명 + .pdf`. URL 경로의 파일명은 필요에 따라 인코딩한다.
- `localhost`는 프로그램을 실행하는 컴퓨터를 가리킨다. 다른 컴퓨터에서 실행할 때는 실제 접근 가능한 서버 주소를 확인한다.

## 해석과 검증 상태

- 텍스트 선택 가능 여부는 텍스트 추출의 완전성·읽기 순서·숫자·수식 정확성이 검증되었다는 뜻이 아니다.
- 그림/그래프와 표의 `미확인`은 그대로 유지한다. `없음`으로 처리하지 않는다.
- OCR 필요 여부와 적용 범위는 기본 추출 결과를 원본 페이지·영역과 비교해 결정하고, 적용·생략 이유를 별도로 기록한다.
- 사용자 관찰을 자동 분석 결과나 검색 평가의 정답 레이블로 사용하지 않는다.
- 원본 PDF의 전체 페이지 수, 언어, 파일 해시, 데이터셋 revision·다운로드 출처, 공식 페이지·요소 ID 매핑은 이 명세서 작성 시점에 미확인이다.
- 문서명은 사용자가 제공한 식별 문자열이다. 별도 검증 없이 MMDocIR 공식 스키마의 특정 ID 필드로 단정하지 않는다.

관련 실습 순서와 검증 항목은 [학습·연구 계획](RAG_LEARNING_PLAN.md)을 참조한다.
