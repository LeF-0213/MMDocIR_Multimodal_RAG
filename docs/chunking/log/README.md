현재 설계는 [청킹 README](../README.md)에 있다.

| 날짜 | 모델 | 기록 | 핵심 | 남은 문제 |
|---|---|---|---|---|
| 2026-11-10 | VL | [첫 청킹: VL](2026-11-10_vl.md) | 첫 VL 파싱 결과로 청크 190개. 신호 있는 청크 53개 대부분이 파싱 문제(영역 병합, 생성 한도 반복)에서 왔다 | 파싱을 고친 뒤 다시 청킹 |
| 2026-11-10 | Structure | [첫 청킹: Structure](2026-11-10_structure.md) | 첫 Structure 파싱 결과로 청크 147개. 표 격자·번호 나열 신호는 파싱 표·차트 문제에서 왔다 | 표·차트 내용은 신호만 붙이고 그대로 |

| 2026-11-11 | Structure | [재파싱·재인식 입력: Structure](2026-11-11_structure.md) | 청크 텍스트·ID는 그대로이고 표 구조 상한 신호 6개가 붙었다 | RAG p6 표 마지막 행·슬라이드 p6 차트 값은 그대로 |
