## 이슈 목록

청킹 단계에서 확인한 이슈를 모듈(처리 순서) > 이슈 유형 > 케이스로 묶었다. 원인이 파싱에 있는 이슈는
파싱 이슈 ID를 함께 적었다. 상태는 현재 기준이고, 각 기록 맨 앞의 이슈 요약에는 그 기록을 쓴 시점의 상태가 있다.
ID는 한 번 붙이면 바꾸지 않는다.

| 상태 | 뜻 |
|---|---|
| 해결 | 원인에 대응했고 결과에서 확인했다 |
| 부분 해결 | 일부만 해결했다 |
| 표시만 | 원인은 그대로 두고 신호로 드러낸다 |
| 미해결 | 원인을 알지만 대응하지 않았다 |
| 한계 | 구현 방식에서 오는 알려진 제약이다 |
| 정상 동작 | 의도대로 동작했고 대응할 필요가 없다 |

현재 상태별 수(13개): 해결 4, 부분 해결 1, 표시만 3, 미해결 1, 한계 3, 정상 동작 1.
