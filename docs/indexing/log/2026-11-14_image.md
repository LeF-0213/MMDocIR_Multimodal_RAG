## 2. ANN 일치율이 확인이 되지 않은 이유

로컬 모드는 HNSW 그래프를 만들지 않는다. 실행 중 qdrant-client가 "Local mode performs exact (brute-force) search,
so `search_params` has no effect" 경고를 냈고 `indexed_vectors_count`도 0이다. 그래서 `exact=False` 요청도 전수 비교로
처리돼, 같은 계산 결과를 서로 비교한 셈이다. 일치율 1.0은 ANN 품질에 대해 아무것도 말하지 않는다.

이 확인으로 알 수 있는 것은 저장이 맞다는 것까지다. 벡터가 float32 반올림 수준 이상 바뀌지 않았고, ID와 벡터의 연결이 꼬이지 않았다.

## 3. 해석과 한계, 다음 단계

- 벡터가 수백 개 규모라 검색도 정확 검색으로 한다. 정확 검색 54번(자기 검색 27 + ANN 요청 27)에 0.09초가 걸렸다.
- ANN 비교는 벡터 수가 늘어 서버 모드로 옮길 때 한다.
- 텍스트 채널 컬렉션은 텍스트 임베딩 뒤 새 인덱싱 실행으로 추가한다. 이미 있는 컬렉션은 덮어쓰지 않는다.
