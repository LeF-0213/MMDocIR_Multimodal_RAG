## 이슈 목록

파싱 단계에서 확인한 이슈를 모듈(파이프라인 순서) > 이슈 유형 > 케이스로 묶었다. 상태는 현재 기준이고,
각 기록 맨 앞의 이슈 요약에는 그 기록을 쓴 시점의 상태가 있다. ID는 한 번 붙이면 바꾸지 않는다.

| 상태 | 뜻 |
|---|---|
| 해결 | 원인에 대응했고 결과에서 확인했다 |
| 부분 해결 | 일부 케이스만 해결했다 |
| 표시만 | 원인은 그대로 두고 신호로 드러낸다 |
| 미해결 | 원인을 조사했지만 대응하지 않았다 |
| 관찰만 | 원인을 조사하지 않았다 |

현재 상태별 수(19개): 해결 2, 부분 해결 1, 표시만 1, 미해결 4, 관찰만 11.
